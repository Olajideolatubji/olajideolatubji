# The Red Ledger — Episode 1 (Remotion build)

A fully rendered 13½-minute YouTube documentary: five corporate frauds, one
running total. Everything on screen is 2D motion-graphics animation rendered
with Remotion at 1920×1080, 30fps.

## Pipeline

1. **Narration** — generated by the Calliope Labs connector (Alex voice, two
   jobs split at the Wirecard/Enron chapter boundary), concatenated into
   `public/voiceover.mp3` (13:26).
2. **Word-level timing** — `scripts/transcribe.py` (faster-whisper, run via the
   `transcribe.yml` GitHub Actions workflow because the sandbox egress policy
   blocks the model download) → `scripts/words.json`.
3. **Timeline** — `scripts/build_timeline.py` fuzzy-anchors every scene cut,
   stat card, ledger open, counter slam and the Enron $90→$0.26 crash chart to
   exact word timestamps → `src/timeline.json`.
4. **Composition** — `src/Main.tsx` renders scenes/overlays/audio from the
   timeline. Music bed (-22dB, ducked -28dB under speech, hard-silenced for
   the second before each stat card) and impact hits are mixed per-frame in
   Remotion. Both audio assets are synthesized by `scripts/gen_audio.py`.
5. **Render** — `npx remotion render Main out/final.mp4` (chrome-for-testing
   mode against the preinstalled Chromium).

## Visual system

- Palette: `#0B0B0D` charcoal, `#EAEAEA` type, `#C1121F` red. Nothing else.
- Film grain + vignette on every frame; every scene has motion.
- Oswald (condensed bold) for numbers, EB Garamond for ledger pages.
- Faceless silhouettes only.
- Recurring elements: the ledger-open ritual, the bottom-right running-total
  counter with chapter-close slams, full-bleed stat cards, word-synced charts.

`chapters.txt` carries the YouTube chapter timestamps.

## Files

- `final.mp4` — the deliverable (72MB, CRF 26 web encode, identical content).
- `assets/master/final_master.mp4.part-*` — the full-quality CRF 19 master
  (179MB), split to fit GitHub's 100MB file limit. Rejoin with:
  `cat assets/master/final_master.mp4.part-* > final_master.mp4`
- `chapters.txt` — YouTube chapter timestamps.
